publications

Selected research publications in video generation, vision-language models, and segmentation.

2026

  1. ICML
    Spectral Heat Flow for Conservative Token Condensation in Vision-Language Models
    Zhaoyang Li, Yanjun Li, Wangkai Li, and 2 more authors
    In International Conference on Machine Learning, 2026
    Abs

    SpecFlow is a training-free token condensation framework for efficient vision-language model inference. It estimates region-consistent visual token importance with spectral heat flow, then applies adaptive token aggregation and pruning to reduce visual redundancy while preserving model performance.

  2. ICLR
    BindWeave: Subject-Consistent Video Generation via Cross-Modal Integration
    Zhaoyang Li, Dongjun Qian, Kai Su, and 6 more authors
    In International Conference on Learning Representations, 2026
    Abs PDF

    BindWeave is a unified subject-to-video generation framework for both single-subject and complex multi-subject scenarios. It uses an MLLM-DiT architecture to ground visual subjects and disentangle their roles, attributes, and interactions.

  3. ICLR
    Adaptive Augmentation-Aware Latent Learning for Robust LiDAR Semantic Segmentation
    Wangkai Li, Zhaoyang Li, Yuwen Pan, and 3 more authors
    In International Conference on Learning Representations, 2026
    Abs PDF

    A3Point is an adaptive augmentation-aware latent learning framework for robust LiDAR semantic segmentation under adverse weather. It captures semantic confusion priors and localizes semantic-shift regions to better exploit diverse weather augmentations.

2025

  1. NeurIPS
    Towards Robust Pseudo-Label Learning in Semantic Segmentation: An Encoding Perspective
    Wangkai Li, Rui Sun, Zhaoyang Li, and 1 more author
    In Advances in Neural Information Processing Systems, 2025
    Abs PDF

    ECOCSeg revisits pseudo-label learning in semantic segmentation from an encoding perspective, replacing one-hot class targets with error-correcting output codes and introducing bit-level pseudo-label denoising.

  2. ICCV
    Generalized Few-Shot Point Cloud Segmentation via LLM-Assisted Hyper-Relation Matching
    Zhaoyang Li, Yuan Wang, Guoxin Xiong, and 3 more authors
    In International Conference on Computer Vision, 2025
    Abs PDF

    LARM is an LLM-assisted framework for generalized few-shot point cloud segmentation. It enriches novel category prototypes with multimodal knowledge and models inter-class structural relationships through hyper-relation matching.

  3. ICML
    Balanced Learning for Domain Adaptive Semantic Segmentation
    Wangkai Li, Rui Sun, Bohao Liao, and 2 more authors
    In International Conference on Machine Learning, 2025
    Abs HTML

    BLDA is a balanced learning framework for unsupervised domain adaptive semantic segmentation. It aligns class-wise logit distributions with shared anchors and uses online logit correction to alleviate class bias under domain shift.

  4. CVPR
    Dual-Agent Optimization Framework for Cross-Domain Few-Shot Segmentation
    Zhaoyang Li, Yuan Wang, Wangkai Li, and 2 more authors
    In Computer Vision and Pattern Recognition, 2025
    Abs PDF

    DATO jointly optimizes domain-invariant feature representations in the frequency domain and rectifies support-to-query matching in the spatial domain for cross-domain few-shot segmentation.

  5. CVPR
    Unbiased Video Scene Graph Generation via Visual and Semantic Dual Debiasing
    Yanjun Li, Zhaoyang Li, Honghui Chen, and 1 more author
    In Computer Vision and Pattern Recognition, 2025
    Abs PDF

    VISA uses visual and semantic dual debiasing for unbiased video scene graph generation, combining memory-enhanced temporal integration with hierarchical semantic fusion.

2024

  1. ECCV
    Localization and Expansion: A Decoupled Framework for Point Cloud Few-Shot Semantic Segmentation
    Zhaoyang Li, Yuan Wang, Wangkai Li, and 2 more authors
    In European Conference on Computer Vision, 2024
    Abs PDF

    DLE first uses agent-level structural correlations to localize confident target regions, then leverages intra-object similarity with a conservative self-expansion strategy to recover complete novel-class objects.
