# Zhaoyang Li

Personal academic homepage for Zhaoyang Li, built with Jekyll and the al-folio theme.

Site: <https://lzy-dot.github.io/zhaoyang/>

## Main Content

- Homepage: `_pages/about.md`
- Publications: `_bibliography/papers.bib`
- CV data: `_data/cv.yml`
- News: `_news/`
- Profile and publication images: `assets/img/`

## Local Preview

The upstream theme recommends Docker for a consistent local environment:

```bash
docker compose up
```

GitHub Pages deployment is handled by `.github/workflows/deploy.yml`.
